ai_reaigame

AIヒロインと会話して仲良くなる、恋愛シミュレーションのモバイルアプリ

2週間で開発 フルスタック モバイル対応 公開URLあり

このアプリは何？

プレイヤーは図書委員の先輩「花（はな）」と出会い、自由にチャットして関係を深めていく恋愛シミュレーションです。
返事は AI（人工知能） が考えるので、毎回違う反応が返ってきます。話し方によって 好感度 が上がったり下がったりして、関係性のフェーズが「知り合い → 気になる存在 → 親しい → 恋人未満」と変わっていきます。

たとえばこんな会話
  • プレイヤー：「本、好きなんですね」
  • 花：「わたしも本が好き。今は星と神話の話を集めた短編集を読んでるの。」 好感度+4
  • プレイヤー：「うざい」
  • 花：「…そういうこと言われると、少し悲しいかも。」 好感度−4

遊び方の流れ

ログイン ▶ キャラ選択 ▶ 冒頭シーン ▶ AIと自由会話 ▶ 好感度が動く

アプリを閉じても、次に開いたとき会話履歴と好感度はそのまま残っています（データベースに保存しているため）。

システムの全体像

アプリは大きく分けて 3つの場所 で動いています。

   [スマホ／パソコンのブラウザ]               ←  プレイヤーが触る画面
            │
            │  HTTPS通信
            ▼
   [サーバー（Render.comに配置）]            ←  会話のやり取りを管理
            │
            ├── データベースに保存（履歴・好感度）
            │      │
            │      ▼
            │   [PostgreSQL（Neonに配置）]
            │
            └── AIに返事を作ってもらう
                   │
                   ▼
                [Google Gemini（AI）]
  • 画面（フロント）：Vercelという無料サービスで公開している
  • サーバー（バック）：Renderという無料サービスで動かしている
  • データベース：Neonという無料Postgresに会話を保存している
  • AI：GoogleのGeminiという無料AIにつないでいる（求人要件のClaudeにも、AWSのBedrockにも、設定1つで切り替え可）

使っている技術（やさしく解説）

React Native (Expo)
画面を作る道具
iPhone / Android / ブラウザの3つで同じコードが動かせる、Facebookが作ったライブラリ。
NestJS
サーバーの土台
「ログインを処理する」「会話を保存する」など、決まった役割ごとにコードを整理しやすくしてくれる。
TypeScript
プログラミング言語
JavaScriptに「型」というルールを追加した言語。間違いをパソコンが先に教えてくれる。
PostgreSQL + Prisma
データベース
会話履歴や好感度を保管しておく場所。Prismaを使うとデータの取り出し・保存が簡単に書ける。
Firebase Authentication
ログイン機能
Googleが提供しているユーザー登録・ログインの仕組み。自分でパスワード管理を作らなくていい。
LangChain
AIをつなげる道具
Claude / Gemini / Bedrockなど、いろいろなAIを同じやり方で呼べるようにする共通の入り口。
Docker
アプリを箱詰めする技術
「どのパソコンでも同じように動く箱」にアプリを詰める仕組み。サーバーへの引っ越しが楽になる。
pnpm + Turborepo
プロジェクトの整理
画面とサーバーを1つのリポジトリにまとめて管理できる「モノレポ」を実現する道具。
Claude Code (SDD)
AI駆動開発
AIアシスタントに「仕様書を見ながら実装して」と頼んで作る進め方。仕様と実装のズレを防げる。
